## ⭐ Featured Project

### 🏗️ [technical-refresh](https://github.com/RathomBoii/technical-refresh)

> A production-grade personal DevOps lab on AWS — built to sharpen platform engineering skills end-to-end.

- Provisioned a complete AWS environment from scratch with **Terraform** — private EKS cluster, bastion host, RDS, and Secrets Manager
- Implemented **GitOps** workload delivery using **ArgoCD** + Helm, with **Traefik** as the ingress layer and custom domain via AWS Load Balancer Controller
- Built a **DevSecOps CI pipeline** on GitHub Actions with OIDC-based AWS authentication (no long-lived credentials), automated ECR image builds, **Trivy** scanning, **Semgrep SAST**, and **Dependabot**
- Secured local AWS credential management using **AWS Vault** — preventing plaintext credential exposure

**Stack:** Terraform · EKS · ArgoCD · Helm · Traefik · GitHub Actions · OIDC · Trivy · Semgrep
